# Nexus

Nexus is a RAG-powered general news aggregator that ingests articles from multiple sources, normalizes and stores them, and enables users to query the news using natural language. The Claude API generates grounded responses anchored to real retrieved articles, eliminating hallucination.

## Goals
- Build a cloud-native event-driven data pipeline on AWS
- Demonstrate RAG architecture with semantic search and grounded AI responses
- Cover technical territory outside prior projects — cloud infrastructure, Python backend, vector databases, deployed AI integration
- Produce strong resume bullets for fall SWE internship recruiting
